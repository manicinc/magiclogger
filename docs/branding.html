Usage Guidelines

Minimum Size

Primary logo: 140px width
Icon: 16px minimum

Clear Space

Maintain clear space equal to the height of the "M" in MagicLogger around all sides

Color Usage

Use gradient version on light backgrounds. Can use monochrome for single-color requirements

Documentation

Use primary logo in README headers, documentation sites, and marketing materials

Code Examples

Icon can be used inline with code examples to highlight MagicLogger usage

Social Media

Use square icon version for profile pictures and social media avatars
